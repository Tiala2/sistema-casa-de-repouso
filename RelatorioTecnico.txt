Relatorio Tecnico - Sistema de Gestao de Casa de Repouso

1. Introducao

O sistema e uma aplicacao desktop Java para apoiar a gestao de uma casa de repouso. Ele centraliza cadastros de idosas, prontuarios medicos, consultas, prescricoes, vacinas, eventos sentinela, profissionais de saude e relatorios operacionais.

A modernizacao manteve Java 8, Maven, MVC, JDBC e MySQL. A interface foi implementada em Swing, sem migracao para web, Spring Boot, JPA ou JavaFX.

2. Arquitetura

- model: entidades do dominio.
- dao: acesso a dados JDBC/MySQL e DAOs em memoria para testes.
- controller: servicos de aplicacao chamados pela interface.
- view: interface Swing, dashboard e paineis dos modulos.
- resources: configuracao local de banco.

3. Banco de Dados

O schema esta em criar_banco_idosoapp.sql e usa MySQL/InnoDB, utf8mb4, indices e chaves estrangeiras nomeadas. A conexao e centralizada em DatabaseConnection e pode ser configurada por application.properties ou pelas variaveis DB_URL, DB_USER e DB_PASSWORD.

4. Interface

A interface Swing possui dashboard, navegacao lateral, listagens, busca local, detalhes, formularios e mensagens de feedback. Listagens, salvamentos e remocoes rodam em background com SwingWorker para manter a janela responsiva.

5. Validacoes

Campos obrigatorios e IDs relacionados sao validados antes da gravacao. Insercoes MySQL capturam o ID gerado. Falhas de consulta e remocao sao comunicadas de forma mais clara.

6. Testes

O projeto usa JUnit Jupiter com Maven Surefire. A suite cobre models e DAOs em memoria.

Comandos:

cd Idosoapp
..\maven\mvn\bin\mvn.cmd -q test
..\maven\mvn\bin\mvn.cmd -q package

7. Limitacoes

Relatorios ainda sao simples, nao ha autenticacao e nao ha migrations versionadas. Alguns models vinculados a prontuario nao carregam prontuario_id na listagem, entao a edicao atualiza apenas campos proprios.

8. Conclusao

O sistema evoluiu para uma aplicacao desktop funcional, com persistencia real, interface organizada, feedback claro e base tecnica consistente, mantendo o escopo Java desktop.
